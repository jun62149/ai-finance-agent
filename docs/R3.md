# 需要调整/确认的问题

## 1. Issue 1：BM25 全量窗口

方案：

```text
window=len(chunk_ids)
```

方向认可。

但实现时请注意：

不要简单删除 window 逻辑。

请保留：

```python
BM25_WINDOW
```

作为未来扩展参数。

建议语义：

```text
BM25_WINDOW=0
    无限窗口

BM25_WINDOW>0
    限制候选数量
```

并在日志中打印：

- 当前 window
- 是否触发窗口限制

避免未来语料增长后静默退化。


## 3. Issue 3：RRF grid

认可做离线实验。

但是提醒：

“最佳参数”。

“在当前评测集上的经验参数”。

<1%

优先保持简单。

## 4. Issue 4：UTC

认可固定 UTC+8。

但是请确认：

代码中所有：

```python
datetime.now()
date.today()
```

相关逻辑是否统一检查。

不要只修：

```python
_date_to_epoch
```

重点搜索：

```bash
grep -R "datetime.now"
grep -R "date.today"
grep -R "timestamp"
```

避免只修一处。

## 5. Issue 5：manifest

认可。

但建议增加一个字段：

```json
{
 "source_db_hash": "...",
 "chunk_count": 109554
}
```

原因：

embedding_version 不一定变化时，数据库内容仍可能变化。

最小方案：

chunk_id_hash 已经够。

如果 source_db_hash 成本低，可以加。

否则不要扩大范围。
