七、as_of 是必须解决的工程问题

原项目目前主要支持：

latest

新项目必须开始支持：

as_of

例如：

get_stock_factors(
    "600519",
    as_of="2026-06-30"
)

以后 Agent 才能回答：

«“2026 年 6 月底的时候，贵州茅台的量化模型怎么看？”»

同时 RAG 评测也需要时间条件。

但是：

绝对不要伪造历史预测结果。

如果当前数据库/模型不能支持某个历史日期：

返回明确的：

NoData

或者：

HistoricalPredictionUnavailable

不要自动退回 latest。

可以先完整实现 factor 的 as_of 查询，再逐步补齐 historical prediction。

八、禁止 sample_data 进入新 API

审计已经发现：

dashboard_service
sample_data

存在空数据库时返回演示假数据的逻辑。

这是网页 Demo 可以接受的设计，但 AI Agent 绝对不能使用。

新 API：

没有数据
→ 返回空结果/结构化错误

不能：
没有数据
→ 返回假数据

否则以后 LLM 会把假数据当成真实股票数据。
