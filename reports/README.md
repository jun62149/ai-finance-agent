# 任务完成报告（新约定 2026-09-08）

本文件夹存放**每次任务完成后新产生的报告**。

## 规则（用户明确要求）

1. 每次任务完成，在本目录**新建**一份报告文件，命名建议：
   `YYYY-MM-DD_简短描述.md`（如 `2026-09-08_公告抓取脚本打磨.md`）。
2. **旧文档一律不再就地修改或追加**，包括：
   - `docs/CONTEXT_HANDOFF.md`（项目总览交接文档）
   - `docs/phase0_report.md`
   - `docs/archive/*`（历史文档归档，来源见交接文档 §3）
   - 设计总纲 `.docx` 等更早文档
3. 历史状态以旧文档为准；新进展/新报告以本目录内最新文件为准。
4. 本 README 例外：它是约定说明，属新建文件，可按需小幅更新。
