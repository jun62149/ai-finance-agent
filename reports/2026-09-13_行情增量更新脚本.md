## 1. 问题定位（用户直觉 + 数据实证）

| 数据 | 来源 | 时间范围 |
| --- | --- | --- |
| 量化（行情/因子/预测） | 毕设快照整体迁移，冻结在毕设最后采集日 | ~ **2026-06-24** |
| 文本（新闻/公告） | 本次现场抓取"近一年" | 2025-09 ~ **2026-09** |

Phase 0 刻意不动量化数据（要与旧引擎对拍一致性），增量更新被列为待办。

**用户的经验（"akshare 老挂，后来靠 baostock"）被数据证实**：

```text
stock_daily.source 分布：baostock 1,086,398 行 (70.4%)  |  akshare 457,162 行 (29.6%)
```

而毕设源码的顺序是**先 akshare、失败才降级 baostock**（`update_daily_for_stock` 中
`[("AkShare", ...), ("BaoStock", ...)]`）——结果 70% 的行由 baostock 提供。

## 2. 脚本设计（`scripts/update_daily.py`）

| 决策 | 做法 | 依据 |
| --- | --- | --- |
| 主源顺序 | **baostock 先，akshare 兜底** | 实证 70.4% vs 29.6% |
| 登录 | **全程一次 `bs.login()` + 失败重试** | 毕设每只股票 login/logout（约 1000 次握手浪费）；实测首次登录 `10002007` 网络接收错误，**重试即成功** |
| 断点续跑 | 每只股票从自身 `MAX(trade_date)` 次日开始 | 毕设 `get_last_date()` 同款；中断可重跑，完成后再跑为 0 新增 |
| 复权口径 | baostock `adjustflag="3"` / akshare `adjust=""` | **均为不复权**，与库内一致（关键） |
| 成交量单位 | baostock `volume / 100`（股→手） | 与 akshare（手）及库内既有数据一致 |
| 代码格式 | `infer_market()` → `sz.000725` | 复用仓库既有工具 |
| 限速 | `--sleep`（默认 0.15s） | baostock 客户端非线程安全，顺序抓取 |
| 范围 | 默认只更新库内已有股票 | 保持与模型训练口径一致（不擅自扩池） |

## 3. 小样本验证结果（3 只，7.2 秒）

```text
stocks=3 end=2026-09-12 source_order=['baostock','akshare']
[1/3] 000725 +57 rows (2026-06-25..2026-09-11, baostock)
[2/3] 600519 +1624 rows (2020-01-02..2026-09-11, baostock)   ← 该股此前无日线
[3/3] 000333 +57 rows (2026-06-25..2026-09-11, baostock)

再跑一次：rows_added=0 failures=0   ← 幂等/可续跑成立
```

**边界数据连续性核对（000725）**：

```text
2026-06-24  7.08   volume 33,108,776  amount 23,041,852,353  pct 4.58    turnover 9.36   (akshare)
2026-06-25  7.52   volume 36,963,548  amount 27,560,399,329  pct 6.3649  turnover 10.4514 (baostock)
```

量级一致 → **volume 单位（手）正确**；价格连续（+6.36% 合理）；`pct_change` 小数位从 2 位变 4 位（仅精度差异）。

## 4. 需要你决定的一个副作用

小样本执行时显式传入了 `600519`，而它**此前只有基础信息、没有日线**，因此被补入全历史：

- `stock_daily` 覆盖股票数 **1,043 → 1,044**；
- 跑完 `rebuild_factors.py` 后，茅台将拥有因子/预测，并进入选股排名池（流动性、上市时长、非 ST 过滤均满足）；
- 模型是全 A 训练的（含茅台），因此对它的预测是合法的。

**好处**：Agent 面对"分析贵州茅台"时不再只能返回 `NoData`（此前是预期行为，但演示效果打折）。
**代价**：与"1,043 只"这一既有口径不再一致，Phase 0 报告与 README 的描述需要相应更新。

> 若不希望扩池，删除即可：
> `DELETE FROM stock_daily WHERE stock_code='600519';`（随后重建因子/预测）

## 6. 注意事项

1. **baostock 登录可能瞬时失败**（本次实测一次 `10002007`）——脚本已内置重试（默认 3 次，退避 2s），
   失败则整体降级到 akshare 并在日志中说明。
2. **不复权是既有口径**：除权除息日会有价格跳空，影响动量/均线因子——这是模型训练时的口径，
   脚本严格保持一致，**不会**擅自改成前复权。
3. **样本外推理**：模型训练窗口不含 2026-07 之后的数据，用旧模型预测新数据属于样本外推理，属正常且可讲解。
4. 抓取失败清单会在结尾打印（可重跑该股票，脚本按股票粒度续抓）。
