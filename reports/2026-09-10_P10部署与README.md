## 2. 构建过程中真实踩到并修掉的两个坑

1. **apt 卡死**：`python:3.12-slim` 默认走 `deb.debian.org`，国内下载 9.7MB 索引 4 分钟无进展。
   → 改为 `ARG APT_MIRROR`（默认清华源，可覆盖为官方源），构建时间从"卡死"变为 16 秒。
2. **torch 回退污染镜像**：原本写了 `pip install torch --index-url <cpu索引> || pip install torch -i <pypi镜像>`，
   首次因 PyPI 读超时触发回退，**把 CUDA 版 torch + nvidia-* 全家桶（已下 723MB 且还在继续）装进了 CPU 镜像**。
   → 改为**不设回退**，并用 `--extra-index-url` 解决传递依赖：CPU 镜像只装 CPU torch（196MB / 127s）。
