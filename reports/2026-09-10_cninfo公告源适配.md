## 1. 背景：为什么要做这件事

东财公告正文接口 `np-cnotice-stock.eastmoney.com/api/content/ann` 对本地 IP 触发**连接级风控**
（成片 `Server disconnected without sending a response`），而列表接口（akshare）一直正常。
实测：单发请求也秒断；东财体系（datacenter/push2/...）共用一套风控，属 **IP 级临时封**，
官方口径是 30–60 分钟自动解除或换网络恢复。

抓取中断时的库状态：公告仅 198 条（000725 一只，且缺 132 条），32 只语料远未完成。

**决策（用户拍板方案 B）**：改用**巨潮资讯网 cninfo（官方指定披露平台）**作为公告数据源，
不再依赖东财公告正文主机。实现参考开源项目
[simonlin1212/a-stock-data](https://github.com/simonlin1212/a-stock-data)（Apache-2.0）的
cninfo 取数方式与 orgId 动态映射思路。

| `requirements.txt` | 新增 `pypdf>=5.0.0` |

关键设计点：

- **orgId 必须动态解析**：cninfo 的 orgId 是异构的（`gssh0600519` / `9900005965` / `GD165627`），
  不能用代码前缀推导；实现为进程内缓存一次 `new/data/szse_stock.json`（6251 条映射）。
- **正文源是 PDF**：`announcementContent` 字段为空，正文在
  `static.cninfo.com.cn/finalpage/YYYY-MM-DD/xxxx.PDF`，用 pypdf 抽文本（中文抽取质量良好）。
- **保持既有契约**：列表行仍返回 `code/title/publish_time/url/art_code`，
  正文仍返回 `(title, content)` 或 `None`，因此续爬/去重/止损逻辑零改动复用。

## 4. 下一步操作（用户本地执行）

```powershell
cd C:\docm\projects\ai-finance-agent

# 1) 清掉东财旧公告（与 cninfo 标题不同，不去重会留两份）
.\.venv\Scripts\python.exe scripts/purge_documents.py --doc-type announcement --source eastmoney --yes

# 2) cninfo 全量抓取（32 只，含正文 PDF）
.\.venv\Scripts\python.exe scripts/ingest_announcements.py --days 365 --max-bodies 300

# 3) 重跑确认幂等（应显示 0 new docs / 0 errors）
.\.venv\Scripts\python.exe scripts/ingest_announcements.py --days 365 --max-bodies 300
```

可调参数：`--workers`（默认 4）、`--delay`（默认 0.15s）、`--page-size`（默认 50）、
`--max-consecutive-fail-stocks`（默认 3，连续全败自动停）、`--refetch-existing`。
若中途断开，直接重跑即可续爬（已入库的 (code,title,date) 会被跳过）。

## 5. 遗留与风险

1. **PDF 解析成本**：年报/半年报动辄 100+ 页，单篇可产生数百 chunks（600519 三篇 → 243 chunks）。
   语料规模会明显大于新闻；Phase 2 建向量时需关注总量与耗时。
2. **抽取质量**：pypdf 对文本型 PDF 效果好；扫描件/图片型公告会抽出空文本（计入 `empty` 计数）。
   如后续发现 empty 偏高，可换 `pdfplumber` 或加 OCR。
3. **新闻仍走东财** `search-api-web`（7743 条已入库），该主机与公告正文主机不同，
   但目前未被封；若后续新闻也被风控，可参考 a-stock-data 的财联社电报/全球资讯作为互备源。
4. **跨源去重键**：续爬键是 `(code, title, publish_time)`，不同源标题格式不同，
   因此换源必须先 purge 旧源（见第 4 节第 1 步）。
5. Hindsight 记忆服务当前未配置 API key（401），本次未能登记 initiative；改以本报告归档。
   如需启用，请配置 `apiToken` / 环境变量后再补登记。
