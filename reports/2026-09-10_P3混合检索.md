## 2. 一个必须更正的说法（诚实记录）

上一份报告里我写过"本地模式 upsert 偏慢、性能不如服务端"——**这是未经测量的推测，实测后不成立**：

| 阶段（模型已预热，109,554 点） | 服务端 Qdrant | 本地模式 |
| --- | --- | --- |
| dense (BGE-M3) | median **36ms**（min 30 / p95 47） | median **31ms**（min 27 / p95 36） |
| BM25 | 1ms | 1ms |
| hybrid (dense+BM25+RRF) | median **32ms** | 35ms |

之前观察到的 15s 是**首次调用里的模型加载**（warm-up 实测 14.1s），不是检索耗时。

**迁移到服务端的真实理由**（依然成立）：

1. **单进程文件锁**——已实测：嵌入任务运行期间，另一个进程连只读打开都失败（`already accessed by another instance`）。API + 脚本并发必然冲突；
2. 官方不建议本地模式超过 2 万点（当前 10.9 万）；
3. 贴合 P10 的 docker compose 目标形态（`docker/docker-compose.yml` 已就位）。

> 结论：迁移是对的，但理由是并发与工程形态，不是单查询延迟。

## 3. P3 交付内容

| 文件 | 说明 |
| --- | --- |
| `app/rag/bm25.py` | jieba(search 模式) 分词 + `bm25s` 稀疏索引；109,554 docs 构建 **132.6s**；索引持久化（`data/bm25/`：index + chunk_ids + metadata）；支持 stock_code/doc_type 后置过滤；**丢弃 0 分命中**（bm25s 会用零分补齐，属噪声） |
| `app/rag/hybrid.py` | RRF 融合（k=60，按 chunk_id 归并，保留 dense_score/bm25_score/rrf_score） |
| `app/rag/reranker.py` | CrossEncoder `BAAI/bge-reranker-v2-m3`；可关闭；**加载失败时降级为融合序并回报 `rerank_error`**，不让请求直接失败 |
| `app/rag/retrieval.py` | `hybrid_search()` 编排（dense+BM25→RRF→rerank），返回每阶段分数与耗时；BM25-only 命中回表补正文；组件单例缓存供后续 RAG Tool 复用 |
| `app/rag/embedding.py` | **离线优先加载**：先试本地 HF 缓存（`local_files_only=True`），失败再联网。模型已缓存时避免远程 HEAD 校验（HF 不可达时会连续超时重试） |
| `scripts/build_bm25.py` | 建索引（`--all-chunks` / `--version` / `--out`） |
| `scripts/search_hybrid.py` | CLI：`--mode dense\|bm25\|hybrid`、`--no-rerank`、`--stock-code/--doc-type`、分数与耗时展示 |
| `scripts/bench_retrieval.py` | 延迟基准：预热后测 dense/bm25/hybrid(+rerank)，可对比本地模式与服务端 |

**测试：77 passed**（P3 新增 12：分词、BM25 检索/过滤/持久化、RRF 融合语义、编排与降级）。

## 4. 你本地待办

```powershell
# 1) 下载 reranker 模型（约 2.2GB，必须走镜像）
$env:HF_ENDPOINT = "https://hf-mirror.com"
.\.venv\Scripts\python.exe -c "from sentence_transformers import CrossEncoder; CrossEncoder('BAAI/bge-reranker-v2-m3', max_length=512)"

# 2) 带 rerank 的混合检索
$env:QDRANT_URL = "http://localhost:6333"
.\.venv\Scripts\python.exe scripts/search_hybrid.py "回购 进展" --stock-code 000725

# 3) rerank 加入后的延迟基准
.\.venv\Scripts\python.exe scripts/bench_retrieval.py --queries 3 --repeat 3
```

> Windows 提示：重定向输出到文件时加 `$env:PYTHONIOENCODING="utf-8"`，否则中文按 GBK 写盘会乱码。
