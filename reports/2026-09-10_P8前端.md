## 1. 交付内容

| 文件 | 说明 |
| --- | --- |
| `frontend/index.html` | 单页结构：提问区（含 4 个示例按钮）→ 执行轨迹 → 量化结果 → 分析报告 → 证据来源 |
| `frontend/app.js` | 无框架交互 + **本地 Markdown 渲染器**（标题/列表/表格/引用/链接/代码），不依赖 CDN，离线演示可用 |
| `frontend/style.css` | 深色单页样式，卡片/表格/标签/证据块 |
| `app/main.py` | 挂载 `/static`，并在 `/` 直接返回页面 —— **一个进程同时提供 UI 与 API** |
| `app/api/chat.py` | `POST /api/chat` 增加 `quant`（量化工具结果）与 `evidence`（证据条目）字段，供前端渲染卡片 |

### UI 展示要点（全部对应铁律）

1. **执行轨迹**：意图（含判定来源 rule/llm）、解析出的股票、计划工具、每次调用的 ok/fail 与参数、
   工具错误码、校验备注（数据缺失、证据不足）——**过程可审计**；
2. **量化卡片**：预测卡（5 日预测收益、综合评分、风险、`strong_prob` 并标注"弱信号"、模型版本、as_of）、
   因子快照表、选股排名表（含主因子）；
3. **报告**：Markdown 渲染，保留「数据事实 / 模型结果 / 推断」的分节结构；
4. **证据来源**：每条含**可点击链接**、doc_type、股票、发布时间、来源、以及
   **dense/bm25/rrf/rerank 四路分数**与正文摘要；
5. **页脚免责声明**：模型分析非投资建议 + 量化 as_of 与新闻时间窗可能不一致的提示。
